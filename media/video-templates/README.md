## LOCKED RULES

1. **Produce BOTH formats for EVERY Market Veggies promotional video.** They need independent layouts — never just stretch/crop the portrait text to make a landscape export.
2. **10 seconds**, three easy-to-read message beats, approximately 0–3 s hook, 3–6 s series/title, 6–10 s call-to-action/URL.
3. **Typography:** visually match the approved **“Build With Us”** reference: large, lively, slightly angled **serif** display lettering in **yellow, orange and white**. The actual font name was not verified; the video masters and supplied reference image are the authority, not a guessed font.
4. **NO TEXT BOXES.** Copy floats directly on-screen: no banners, shapes, backplates, rectangles, pills, or colored cards.
5. **Portrait:** text at the top/bottom of a centered illustration on royal-blue backdrop. Protect faces, book, and logo.
6. **Landscape:** text to the LEFT, original artwork and book to the RIGHT. Correct v3 layout prevents all clipping and overlap.
7. **Audio:** use the supplied original **Market Veggies theme song**, keeping the actual **10-second segment from the approved video** as the default. Do not replace it with generic background music.
8. **Motion:** subtle movement of original picture, bouncy readable text, and smooth transitions, referencing the approved exports.
9. **Artwork authenticity:** use the original characters/images from project assets (especially actual Gary). Do NOT recreate or substitute lookalike AI versions.
10. **QA every new promo:** both aspect ratios; titles visible and not overlapping; text not obscuring characters; URL correct; 10 seconds; song audible; no watermark; works on phone and desktop.
11. **Copy changes by campaign:** for the Book 1 example, beats were “Good Reads For All Little Monsters” → “Market Veggies” → “Get Your Copy TODAY!” with the Book 1 URL. For other produce characters, recipes, events, etc., update the message and link while preserving the production template.
12. **Preserve immutable masters.** New versions get new filenames; never silently replace the approved vertical v2 and landscape v3 examples.
